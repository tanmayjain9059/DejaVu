## Source-only button and additions

`copyPublicTrackingLink` (Copy private link) is the only source-only button ID. **Do not add:** unified already has Copy reference; a secret-bearing URL conflicts with its current tracking contract. Keep `copyPublicTrackingReference`, `publicTrackReference`, `publicTrackRoll` and `publicTrackSecret`.

**Added workflow buttons: none.** Track, claim, requested evidence, privacy action/export, office review and physical handover already have controls. Dynamically rendered controls remain in their existing JS renderers/dispatchers; all 100 baseline named JS functions and API expressions are retained.

## Source issues excluded from the port

The teammate branch contains backend/config/test changes as well as visuals. None of those are imported. Its JS adds mock authentication/records and changes tracking to URLs and session storage, and its markup makes the linked Lost report optional for claims. These are behavior/security changes, not visual interactions, and are excluded. Existing authorization, secret headers, claim requirements, public redaction and real API calls remain authoritative.

The useful visual delta from the latest head is the blue Lost / amber Found material treatment, ambient colors, specular buttons and new detective SVG. It does not provide new visual interaction code beyond the earlier source; the existing local spring/badge implementation is retained.
